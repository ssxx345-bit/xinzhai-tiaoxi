# 心齋調息

隨時打開的喘息角落。單一 HTML 檔，不需要安裝或建置，用瀏覽器直接開 `index.html` 就能用。

## 功能

- **呼吸**：4-7-8 放鬆、方塊呼吸、共振呼吸、生理嘆息四種節奏。點中間的圓開始，外圈刻度盤顯示目前進度。
- **聲景**：雨、海浪、營火、壁爐、風、溪流、鳥鳴、頌缽、棕噪音，全部由 Web Audio 即時合成，沒有任何音檔。可以自由混音，並另存成自己的情境。
- **專注**：15 / 25 / 50 / 90 分鐘計時，時間到響頌缽；計時中會讓螢幕保持亮著。
- **放下**：把煩惱寫下來，字會散成光點飄走。內容不會儲存。
- **著陸**：5-4-3-2-1 五感練習，附台灣求助專線。

## 資料

所有偏好（音量、節奏、自訂情境、今日統計）只存在瀏覽器的 localStorage，不會傳到任何地方。

## 參考

溪流的合成方式參考 SuperCollider 官方範例 [babbling brook](https://github.com/supercollider/supercollider/blob/develop/examples/demonstrations/babbling%20brook.scd)（James McCartney）。
